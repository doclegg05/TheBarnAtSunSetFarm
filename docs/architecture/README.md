# Architecture reviews

Snapshots of architecture reviews: places where the code could be restructured
so changes land in one place and are easier to test. Open the HTML files in a
browser; they load Tailwind and Mermaid from public CDNs.

- `review-2026-10-19.html`: the `/experience` page and the lodging feed sync.
  Top recommendation: deepen the scroll film module, so each scroll film (the
  descent, the walk into the barn, and the lawn, sunset and stars films still
  to come) is one definition instead of edits across five files.

These are proposals, not decisions. Nothing in them has been carried out yet.
