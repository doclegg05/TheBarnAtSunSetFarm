Problem. initMotion looks deep, but its real interface is a silent contract of 49 class-name strings and an ordering rule. Renaming one hook drops a pin with no error, and every later trigger shifts.

Solution. Each chapter module owns both its markup and its motion recipe, joined by refs. The page mounts the chapters in page order, so ScrollTrigger order follows by construction.

  • Locality: a chapter changes in one file
  • Renames break the build, not silently
  • Ordering rule moves inside the page
  • Interface shrinks to chapter list

Problem. "Email about this exactly once" is spread across five modules with three dedupe schemes. The send-then-mark order is held by convention, and the mark-failure paths are untested.

Solution. One alert-once module owns the key, the already-sent check, the send, the record and the failure policy. The two existing adapters, the Mailer fake and pglite, stay as they are.

  • Locality: dedupe rules in one place
  • Mark-failure paths become testable
  • Real seams: Mailer ×3, Rpc ×2
  • sync.ts loses four call shapes

5. Let the conflict rules return what sync needs

After: collapsed

conflict rules module

Problem. The pure conflict functions drop information their callers need, so the callers re-derive rules. The lookback is written twice, and "future stay" is defined once in JS and once in SQL.

Solution. The conflict rules module returns pairs and owns the lookback and "future stay" rules.

  • Locality: rules stop drifting apart
  • Existing pure tests keep working

Considered, not proposed

store.ts: shallow, a 1:1 match to the SQL functions, but it passes the deletion test as the row decoder. Leave it.

lib/scheduling availability (computeSlots, rules): well tested, but nothing in production calls it. YAGNI: deepen it when a booking endpoint exists.

Top recommendation

Deepen the scroll film module

It's the hottest code in the repo, its friction is concrete (pin length written three times, captions matched by position), and the shot list calls for three more films: lawn, sunset and stars. Each would cost one definition instead of five edits.
